# האוסף הבוטני של רפאל

דשבורד אינטראקטיבי (עברית, RTL) לאוסף צמחים מיובשים. האוסף נעשה על ידי רפאל דורון בתחילה כתחביב והפך לחלק מהמשימות לתואר ראשון במדעי הטבע.

## הפעלה
- פתיחת `index.html` בכל דפדפן, או דרך GitHub Pages (ראו למטה).
- אין צורך בהתקנה או באינטרנט.

## קבצים
| קובץ | תיאור |
|---|---|
| `index.html` | הדשבורד (HTML/CSS/JS בקובץ אחד, הנתונים מוטמעים) |
| `תמונות/` | 55 תמונות הצמחים היבשים (JPG מוקטן) |
| `SPEC.md` | אפיון הפרויקט |

קבצי המקור (אקסל ואלבום Word) נשמרים אצל בעלת הפרויקט ואינם בריפו.

## GitHub Pages
האתר מוגש מהענף `main` (root). הכתובת: https://yaeledoron-eng.github.io/rafael-botanical-collection/

## טבלת נתונים
הכפתור "📋 טבלת נתונים" בדשבורד פותח טבלה בסגנון Airtable (חיפוש, מיון, סינון וקיבוץ). לחיבור תצוגה חיה מ-Airtable מדביקים קישור שיתוף ל-`AIRTABLE_SHARE_URL` ב-`index.html`.

מפרט מלא: [SPEC.md](SPEC.md)
